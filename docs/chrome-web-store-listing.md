## 短說明

> Clean Trail 在瀏覽器本機移除分享網址中的追蹤參數，保留有用內容，支援自訂規則、白名單與快捷鍵。

## 詳細說明

分享連結前，先把追蹤尾巴清掉。

無痕清理器｜Clean Trail 是本機優先的瀏覽器擴充功能，會在頁面載入後整理網址，移除已知的 UTM、Facebook、Google Ads、Instagram、TikTok、郵件與常見亞洲平台追蹤參數。頁面內容不重新載入，網址路徑、未知參數與 `#` 片段預設保留。

你可以依照自己的工作流繼續調整：

- 使用內建規則，自動整理常見分享網址。
- 新增精確名稱、萬用字首或正則表達式規則。
- 從 HTTP(S) JSON／純文字清單訂閱規則，失敗時保留上一份有效版本。
- 用 Popup 加入網域白名單，或暫停全域清理。
- 對連結按右鍵，或使用 `Ctrl+Shift+Y`（macOS：`Command+Shift+Y`）複製清理後的 URL。

資料處理保持透明：清理、規則比對與設定都留在你的瀏覽器。Clean Trail 不建立瀏覽歷程、不使用自有分析、不要求登入，也不把目前網址送到 Clean Trail 的伺服器。訂閱只會讀取你明確加入的外部規則網址；外部來源的請求紀錄則依來源網站自己的政策處理。

這不是網路層防追蹤工具。網址列是在頁面載入後整理，不能撤回網站在初始請求時可能已經收到的原始 URL。需要阻止請求本身時，請搭配適合的網路層工具。

## 單一用途說明

Clean Trail 的單一用途是：在使用者瀏覽或分享網址時，於本機移除追蹤參數，降低不必要的網址曝光與分享噪音。

## 權限用途說明

請依照實際 Manifest V3 權限填入 Dashboard：

- `storage`：保存自訂規則、白名單、全域暫停狀態、訂閱網址與同步後的規則快取。
- `contextMenus`：建立連結右鍵選單中的「複製無痕連結」。
- `alarms`：每六小時執行一次使用者已加入的規則清單同步。
- `tabs`：讀取目前分頁 URL，供 Popup、快捷鍵與右鍵複製使用。
- `scripting`：在部分頁面無法使用一般內容腳本時，提供使用者主動要求的複製 fallback。
- `clipboardWrite`：只在使用者按下複製、使用右鍵功能或快捷鍵時寫入清理後的 URL。
- `<all_urls>`：讓清理器能在不同網站的頁面 URL 上工作；瀏覽器特殊頁面仍不會注入。

## 隱私聲明填寫重點

- **是否收集使用者資料**：否；擴充功能會在本機處理目前 URL 和設定，但不把它們收集或傳輸到 Clean Trail。
- **是否處理瀏覽活動**：是，僅為完成網址清理這個單一用途；處理結果留在使用者瀏覽器。
- **是否出售或移轉資料**：否。
- **是否使用資料進行信用、貸款、保險、健康或其他敏感推論**：否。
- **隱私政策 URL**：<https://yazelin.github.io/url-no-trace/privacy.html>
- **Limited Use 說明**：資料只用於使用者可見的網址清理、複製、規則設定與使用者主動加入的規則同步，不用於廣告、分析、信用評分或其他無關用途。

## 審查者快速驗證

1. 安裝套件後，造訪 `https://example.com/?utm_source=review&keep=1`。
2. 確認頁面載入後網址變成 `https://example.com/?keep=1`，且頁面沒有重新載入。
3. 開啟擴充功能設定，新增一條自訂規則，確認設定可以保存。
4. 在 Popup 暫停全域清理，再重新載入測試網址，確認參數會保留；恢復後再次確認會清理。
5. 以 `Ctrl+Shift+Y` 測試複製目前分頁的清理後 URL；快捷鍵也可在 `chrome://extensions/shortcuts` 重新指定。
