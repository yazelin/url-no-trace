01 / WHY CLEAN TRAIL

網址可以很長，
不必把你也一起帶出去。

你從社群、電商或搜尋結果複製一個連結時，網址後面常常跟著一串看不懂的參數。它們可能用來辨識廣告來源、點擊活動或分享渠道；對收件人來說，通常只是噪音。

Clean Trail 的任務很單純：辨認已知的追蹤參數，移除它們，保留頁面路徑、你真的需要的查詢值，以及 # 後面的頁面狀態。

04 / PRIVACY, WITHOUT MARKETING FOG

我們把「不會做什麼」也寫出來。

Clean Trail 改善的是網址分享、複製與曝光，不是假裝自己能攔截所有網路追蹤。這個邊界很重要，也讓工具的承諾更可信。

06 / GOOD QUESTIONS

開始前，先回答幾個實際問題。

它會不會把正常的網址參數刪掉？＋

預設只處理已知規則，未知參數保留；網址路徑與 # 片段也保留。你也能替特定網站加白名單，或暫停全域清理。

它和完整的廣告／追蹤阻擋器一樣嗎？＋

不一樣。Clean Trail 專注在「網址列和分享出去的連結」；它是在頁面載入後整理網址，不能阻止網站收到初始請求，也不取代網路層阻擋工具。

規則清單會不會執行遠端程式碼？＋

不會。訂閱內容只當作 JSON 或純文字規則解析，不使用 eval、new Function 或遠端 script 注入；而且只有你明確加入的網址會同步。

目前可以直接從商店安裝嗎？＋

目前還沒有上架 Chrome Web Store 或 Firefox Add-ons，這個版本需要用瀏覽器的開發人員模式載入。原始碼與測試都在 GitHub 公開。
